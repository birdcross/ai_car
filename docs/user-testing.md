# EV Log 사용자 테스트 기록

2026년 11월 25일 기준 참여자 5명의 설문 응답을 확인했다. 점수와 익명 의견은 [README의 실사용자 평가 결과](../README.md#실사용자-평가-결과)에 정리했다. 개발자가 테스트한 API나 샘플 결과는 참여 인원에 포함하지 않는다.

## 공통 과제

1. 배포 사이트에서 로그인하고 차량을 등록한다. 설명서 검색 검증에는 현대 코나 일렉트릭 2025년형을 사용할 수 있다.
2. 테스트 계기판 사진만 보내 경고 이름과 공식 설명서 링크를 찾는다.
3. 지난 대화를 다시 열어 후속 질문을 보낸다.
4. 차계부에서 정비 내용을 입력하고 저장한 기록에서 비고를 찾는다. 테스트용 금액을 사용한다.

## 진행자 질문

- 설명서 링크를 어디에서 확인했나요?
- 답변을 받고 다음에 무엇을 확인할지 이해했나요?
- 어디에서 막히거나 다시 시도했나요?
- 실제로 쓸 때 가장 먼저 고치면 좋을 점은 무엇인가요?

## 운영 최종 테스트

2026년 11월 25일에 로그인한 테스트 계정으로 Vercel 운영 사이트를 점검했습니다. 현대 모니터링과 주행 경로에는 공식 규격서 예시와 테스트 데이터를 사용했습니다. [운영 사이트](https://aicar-qyat.vercel.app/) · [검증한 앱 버전](https://github.com/birdcross/ai_car/commit/16de6f59714d103dd28f877d4f77b281d447048b)

| 항목 | 확인한 결과 |
| --- | --- |
| 로그인·회원가입 | 로그아웃 상태에서 모니터링 대신 로그인 화면이 표시되고, 로그인 후 계정 메뉴와 등록 차량이 표시됩니다. 회원가입 입력 항목과 개인정보 동의 화면을 확인했습니다. 이번 점검에서 새 가입 확인 메일 발송은 검증 범위에 포함하지 않았습니다. |
| 차량 모니터링 | 연결된 차량이 없을 때 연동 안내가 표시됩니다. 현대 공식 예시 모드에서 배터리 51%와 잔량 그래프를 확인했습니다. 실제 차량 데이터 수신과 자동 이상 감지는 연결된 차량으로 확인해야 합니다. |
| 경고등 AI·설명서 | 텍스트 질문과 합성 계기판 사진의 `CHECK TIRE PRESSURE`를 입력해 2025 코나 일렉트릭 공식 설명서 발췌와 링크를 확인했습니다. 사진 전송 동의가 필수이며, 새로고침 후 지난 대화에서 인식 문구와 출처를 다시 열 수 있습니다. 지난 대화에는 첨부 이미지가 표시되지 않습니다. 이번 결과에 표시된 검색 경로는 공식 설명서 발췌입니다. 운영 벡터 검색 경로는 이 점검에서 별도로 확인하지 못했습니다. |
| 주차·주행 지도 | 저장된 테스트 주소가 먼저 표시되고, 지도 버튼을 눌러야 주차 주변 지도 타일을 불러옵니다. 날짜별 예시 주행을 선택해 주차 지도와 주행 지도가 한 화면에서 함께 표시되는 것을 확인했습니다. |
| 차계부 | 충전 유형에서는 충전량(kWh), 정비 유형에서는 정비 내용(비고)이 표시됩니다. 운영 계정에 신규 지출을 저장하는 테스트는 이번 점검 범위에서 제외했습니다. |
| CODEF 카드사 | 로컬 샌드박스에서 테스트 카드 3개와 첫 카드의 승인내역 1건을 조회했습니다. 운영 Vercel은 샌드박스 환경 변수가 필요하다는 응답을 반환했습니다. |
| 보안 | 운영 AI API가 비로그인 요청에 HTTP 401을 반환합니다. 운영 DB에서 사용자 데이터의 RLS와 소유자 정책, 서버 전용 차량 토큰 권한을 확인했습니다. 분당 AI 요청 8건 허용과 9번째 차단을 DB에서 확인했습니다. Vercel 응답의 콘텐츠 보안 정책, 프레임 차단, 차량 인증 콜백의 Referrer-Policy 적용을 확인했습니다. |

점검 중 영어 경고 문구가 일반 AI 안내로 분류되던 문제와 주차·주행 지도 중 두 번째 지도가 열리지 않던 문제를 수정한 뒤 운영에서 다시 테스트했습니다.
