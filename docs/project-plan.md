# EV Log 기획서

## 문제와 대상

전기차 운전자는 계기판에 처음 보는 아이콘이 켜지면 아이콘 이름을 알아내고, 내 차종과 연식의 설명서를 찾아 조치 방법을 확인해야 한다. 충전이 멈췄을 때도 차량이 언제 마지막으로 상태를 보냈는지부터 확인해야 한다. 우선 대상은 전기차를 처음 운전하거나 제조사 설명서를 자주 찾는 국내 운전자다. 이 문제가 얼마나 자주 발생하는지는 실사용자 테스트에서 확인한다.

## 제안

계정에 차량을 등록하고, 계기판 사진이나 질문을 올리면 관련 설명서 근거와 확인 순서를 볼 수 있게 한다. 모니터링은 수신한 충전 상태와 전송 시각을 보여주고, 목표에 도달하기 전의 충전 중단과 데이터 지연을 안내한다. 충전비와 정비 내역을 차계부에 기록할 수 있다.

## 일정과 확인 기준

| 단계 | 산출물 | 확인 기준 |
| --- | --- | --- |
| 문제 정의와 범위 결정 | 기획서, 사용 시나리오 | 대상 사용자가 겪는 문제와 핵심 행동을 한 문장씩 설명한다. |
| 구현 | 요구사항 문서, 저장소 | 텍스트·사진 질문과 출처가 있는 답변, 차량 설정과 차계부가 동작한다. |

| 사용자 검증과 개선 | 사용자 테스트 기록, 변경 커밋 | 실제 사용자 5명 이상이 직접 사용한다. 관찰한 문제를 수정하고 재확인한다. |

팀 제출이라면 발표 전 실제 팀원과 담당 범위, PR·테스트 등 각자의 기여 근거를 README에 기입한다. 개인 제출이라면 담당 범위와 개발·배포·테스트 중 직접 수행한 일을 정리한다.
